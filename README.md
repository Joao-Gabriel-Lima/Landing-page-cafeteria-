Coffee House

Landing page de uma cafeteria desenvolvida com foco em um design moderno, elegante e responsivo.

O projeto foi criado para praticar conceitos de desenvolvimento Front-end, trabalhando principalmente com estruturação de páginas, estilização, responsividade e organização de código.

## Tecnologias

* **HTML5** — Estrutura e semântica da página
* **CSS3** — Estilização, layout e responsividade
* **JavaScript** — Interações e funcionalidades

## Características

* Página temática para cafeteria
* Design responsivo
* Interface moderna e elegante
* Navegação entre seções
* Uso de imagens para composição visual
* Estrutura organizada em HTML e CSS

## Objetivo do projeto

O objetivo deste projeto foi desenvolver uma landing page completa utilizando tecnologias fundamentais do Front-end, colocando em prática conceitos de:

* Estruturação semântica com HTML
* Flexbox e Grid
* Responsividade
* Tipografia e cores
* Organização de CSS
* Desenvolvimento de interfaces

## Aprendizados

Durante o desenvolvimento, pude aprimorar meus conhecimentos em criação de layouts, responsividade, posicionamento de elementos, utilização de imagens e construção de interfaces voltadas para uma experiência de usuário agradável.
